# 1. 数据库

使用：

> PostgreSQL

目标：

> 足够支持个人使用，同时保持结构清晰。

# 12. Application Form Field

如果第一版需要保存表单分析结果，可以建立：

## application_fields

``` text
id
application_id
field_name
field_label
field_type
mapped_source
confidence
is_sensitive
is_filled
```

例如：

``` text
field_label = "最高学历"
mapped_source = "education.degree"
confidence = 0.98
is_sensitive = false
```

身份证：

``` text
field_label = "身份证号"
mapped_source = null
is_sensitive = true
is_filled = false
```

# 15. Index

重点索引：

``` text
jobs(company_name)
jobs(title)
jobs(location)
jobs(match_score)
jobs(created_at)
jobs(status)

applications(status)
applications(created_at)

job_carts(user_id)
```

岗位列表筛选依赖数据库查询。

不要把全部岗位加载到前端。

``` text
 ↓

 ↓
Application
 ↓
Browser Task
 ↓

 ↓
Interview
 ↓

```

------------------------------------------------------------------------

# 17. 数据安全

敏感数据原则：

> 不存就最好。

第一版：

-   身份证：不存
-   银行卡：不存
-   招聘网站密码：不存
-   验证码：不存
-   MFA：不存

招聘网站登录态由 Playwright 本地浏览器管理。
